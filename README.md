Fishing Store Inventory Manager

Business Problem:
A small fishing store often runs out of popular fishing products during busy periods. The manager needs a simple way to track inventory and determine when products should be restocked.

Business Question:
What reorder level should the store use to reduce how often popular fishing products run out of stock?

How to RUn:
1. Open the project folder in VS Code.

2. Run Main.py in the terminal using python Main.py.

3. Choose an option from the menu.

Menu Options:
1. View inventory
2. Add or restock an item
3. Record a sale
4. Show low-stock alerts
5. Sales report with charts
6. Run 30-day simulation
7. Save and exit

Files:
Main.py - Runs the menu and main program.

inventory.csv - Stores fishing product information, prices, quantities, and reorder levels.

sales.csv - Stores recorded sales transactions.
